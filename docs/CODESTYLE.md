# Codestyle

We use [this](https://gist.github.com/df604f2bf65a506223464e3ffd96a78a.git) codestyle in our project.

## Automatic formatting

The machine-readable formatting rules live in `.clang-format` in the
repository root. The configuration is `BasedOnStyle: Google` adjusted
to the project style described in `docs/style.md`: 80 columns, 4-space
indentation, wrapped braces indented one level deeper with the body
aligned to the brace, spaces inside parentheses, pointer stars next to
the type.

Use the pinned clang-format version, otherwise the formatting output
may not match:

    pip install clang-format==23.1.5
    clang-format -i <file>

`PAC/common/PAC_dev_lua.cpp` is generated by toluapp and is kept out of
the formatting file list.
