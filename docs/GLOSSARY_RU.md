# Глоссарий терминов ПТУСА

Общий русско-английский словарь терминов, применяемых в
ПТУСА.

## Правила заполнения

- Новую запись добавляют, когда перевод термина впервые
  введён в тексте или принят в ревью.
- Формат записи: `- Термин — English: краткое пояснение.`
  Ссылка `([подробнее](файл))` ведёт на документ с
  подробным описанием, если такой документ есть.
- Запись не дублируют: при уточнении перевода правят
  существующую запись.
- Внутри раздела записи идут по алфавиту; новый раздел
  создают только для цельной группы терминов.

## Ревью и CI

- двоичные исполняемые файлы — binaries: файлы программ,
  создаваемые сборкой.
- журнал (лог) — log: последовательная запись событий; при
  неочевидности уточняют вид (`журнал событий`,
  `журнал сборки`).
- запрос на внесение изменений — pull request: предложение
  влить изменения в `master`.
- кросс-сборка — cross build: сборка для другой платформы
  или компилятора.
- конвейер — workflow: автоматический сценарий сборки и
  проверок в `.github/workflows/`.
- метка — gate marker: служебный маркер CI-гейта
  (например, `version_ok`).
- плавающий тест — flaky test: тест, который то проходит,
  то падает без изменения кода.
- прогон — run: один запуск конвейера (`workflow`).
- сборочная матрица — build matrix: перебор комбинаций
  платформы и компилятора в одном конвейере.
- фиксация в master-ветви — push: отправка коммитов в
  `master`
  ([подробнее](RELEASE_PROCESS_RU.md)).

## Релиз

- вложения релиза — assets: файлы, прикрепляемые к релизу
  ([подробнее](RELEASE_PROCESS_RU.md)).
- выпуск релиза — cutting a release: подготовка черновика
  релиза с новым номером версии
  ([подробнее](RELEASE_PROCESS_RU.md)).
- номер версии — version string: CalVer-номер вида
  `2026.11.18.0`
  ([подробнее](CONTRIBUTING.md#versioning-and-tags)).
- примечания к релизу — release notes: описание изменений
  релиза
  ([подробнее](RELEASE_PROCESS_RU.md)).
- публикация — Publish: перевод черновика релиза в
  опубликованные (`gh release edit --draft=false`)
  ([подробнее](RELEASE_PROCESS_RU.md)).
- тег релиза — release tag: тег с номером версии
  ([подробнее](CONTRIBUTING.md#versioning-and-tags)).
- черновик релиза — draft: неопубликованный релиз с
  примечаниями и вложениями
  ([подробнее](RELEASE_PROCESS_RU.md)).

## ПАК и технологические объекты

- датчик — sensor: устройство, считывающее измерение с
  оборудования.
- исполнительное устройство — actuator: устройство,
  воздействующее на технологический процесс.
- команда принудительного сохранения — FORCE_SAVE_PARAMS:
  команда монитора `system cmd 102`.
- операция — operation: упорядоченная последовательность
  шагов технологического объекта.
- ПАК — programmable automation controller (PAC):
  программируемый контроллер, термин контекста АСУ ТП.
- параметры — controller parameter set: набор параметров
  контроллера, которым управляет `params_manager`.
- технологический объект — technology object: управляемый
  объект: оборудование с набором операций.
- циклическое автосохранение — periodic autosave:
  регулярное сохранение параметров контроллера по таймеру.
